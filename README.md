
# SuperStore Sales Dashboard – Power BI

## 📊 Overview
This project presents an interactive SuperStore Sales Dashboard built using Microsoft Power BI to analyze sales performance, profitability, customer segments, and regional trends. It transforms raw sales data into meaningful insights to support data-driven business decisions.

## 🎯 Objectives
- Analyze overall sales and profit performance.
- Identify sales trends over time.
- Evaluate the performance of product categories and sub-categories.
- Understand regional and customer segment performance.
- Build an interactive dashboard for business analysis.

## 🚀 Key Features
- **Sales Analysis:** Track sales performance and revenue trends.
- **Profit Analysis:** Evaluate profitability across different categories.
- **Time-Series Analysis:** Monitor sales trends over time.
- **Category Analysis:** Compare product categories and sub-categories.
- **Regional Analysis:** Analyze sales across different regions and states.
- **Interactive Dashboard:** Explore data using filters, slicers, and visualizations.
- **KPI Cards:** Display key business performance indicators.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization
- Business Intelligence

## 📈 Key Insights
The dashboard helps explore:
- Sales and profit trends.
- Best-performing product categories.
- Regional sales performance.
- Customer segment contributions.
- Opportunities to improve business profitability.
